


# LLM From Scratch

This repository is my learning project where I am building a **Large Language Model (LLM) from scratch**.

I am following the book **"Build a Large Language Model (From Scratch)" by Sebastian Raschka** and implementing the concepts step by step.

## What I am Learning

* Python for LLM development
* Tokenization
* Creating datasets
* Embeddings
* Attention mechanism
* Transformer architecture
* Training an LLM
* Building a GPT-style model
* Text generation

## Project Structure

```text
LLM-from-Scratch/
│
├── notebooks/       # Experiments and learning
├── datasets/        # Dataset files
├── src/             # Model implementation
├── README.md
└── requirements.txt
```

## Goal

The main goal of this repository is to understand **how LLMs work internally** by building one step by step instead of only using existing libraries.

This is mainly a **learning and experimentation project**, so the code may change as I learn new concepts.
